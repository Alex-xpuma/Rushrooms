🍄 Rushrooms

Rushrooms is a 2D casual game project created in Unity and C#.

The game combines different mushroom-themed worlds and gameplay modes. The project was created as an academic game development project, with a focus on designing and implementing original gameplay mechanics and an engaging visual style.

🎮 Gameplay

Rushrooms features multiple gameplay modes:

Mushroom Merge — a 2048-inspired game mode where players combine mushrooms to unlock new ones.
Mushroom Runner — a runner-style gameplay mode where the player controls a mushroom character and navigates through the scene.
Mushroom Collection — a planned collection/management scene where players can view the mushrooms they have unlocked.
